# Hanane Bellala — Portfolio

A creative, modern, and responsive React portfolio application built with Vite, Tailwind CSS, Framer Motion, and Lucide React.

---

## Design System & Colors

- **Deep Plum / Wine**: `#491B37`
- **Soft Ice Blue**: `#D0E4FF`
- **Warm Cream / Off-White**: `#FFF8EE`

---

## Custom Typography

The project is preconfigured to use:
1. **Monthey** 
2. **Playfair Display** 
3. **Photograph Signature**

## Sections Included

1. **Landing Hero**
2. **About Me**
4. **My Skills**
5. **My Projects**
6. **Beyond Work**
7. **Thank You / Contact**

## 💻 Development Commands

```bash
# Run local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
