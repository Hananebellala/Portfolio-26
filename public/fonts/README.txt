=== FONTS DIRECTORY ===

Please place your custom font files here in this folder (`public/fonts/`):

1. Monthey font:
   - Monthey.woff2, Monthey.woff, Monthey.otf, or Monthey.ttf

2. Playfair Display font (optional, already loaded via Google Fonts as well):
   - PlayfairDisplay.woff2, PlayfairDisplay.ttf, or PlayfairDisplay.otf

3. Photograph Signature font:
   - PhotographSignature.woff2, Photograph Signature.ttf, PhotographSignature.otf, or Photograph-Signature.ttf

The CSS in `src/index.css` is already preconfigured to load these files automatically as soon as they are placed here, with automatic fallback to elegant Google Fonts so everything renders beautifully!
